⚠ Warning: The delete endpoints aren't protected. For safety, those endpoints are commented out by default in app.py. If you want to use them, first uncomment them and restart the application. When you are done using the endpoint, please comment them again.

add skill to the database

http://localhost:5000/insertskill?name=skillname&level=80&category=categoryname

get skill from the database

http://localhost:5000/getskill?name=skillname

get all skills from the database

http://localhost:5000/getallskills

delete a skill from the database

http://localhost:5000/deleteskill?name=skillname

add project to the database

http://localhost:5000/insertproject?name=projectname&description=description%20about%20the%20project&footer=projectfooter&tags=python,flask,mongo&image=https://example.com/image.webp

get project from the database

http://localhost:5000/getproject?name=projectname

get all projects from the database

http://localhost:5000/getallprojects

delete a project from the database

http://localhost:5000/deleteproject?name=projectname

add experience to the database

http://localhost:5000/insertexperience?title=jobtitle&role=developer&period=2024-2026

get experience from the database

http://localhost:5000/getexperience?title=jobtitle

get all experiences from the database

http://localhost:5000/getallexperiences

delete experience from the database

http://localhost:5000/deleteexperience?title=jobtitle

add tech stack item to the database

http://localhost:5000/inserttech?name=python&label=Python&image=images/python.webp&alt=python

get tech stack item from the database

http://localhost:5000/gettech?name=python

get all tech stack items from the database

http://localhost:5000/getalltechstack

delete tech stack item from the database

http://localhost:5000/deletetech?name=python
